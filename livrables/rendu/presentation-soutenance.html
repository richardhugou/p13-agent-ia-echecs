L'histoire

L'histoire et le besoin

La FFE prépare ses jeunes espoirs aux championnats d'Europe. 60 000 licenciés, ~60 % de jeunes, quelques centaines d'entraîneurs diplômés — le goulot d'étranglement, c'est l'humain.

Imaginez Léa, 12 ans : elle veut travailler ses ouvertures ce soir, son entraîneur n'est pas disponible.
La commande d'Alan : un POC en deux semaines — une IA qui l'accompagne pendant qu'elle joue.

Ce que l'IA doit savoir faire pour elle :

1 · proposer les coups reconnus par la théorie
2 · expliquer les idées, sources citées
3 · recommander des vidéos adaptées
4 · évaluer objectivement hors des sentiers battus

L'architecture — chaque brique et son intérêt

vert = sources de vérité · terracotta = rédaction · le LLM ne choisit jamais un coup · chaque brique a un plan B (dégradation observée en réel) · MongoDB cache tout (théorie 24 h, évals, vidéos 7 j)

L'architecture · Le cœur documentaire

La base vectorielle, expliquée

Le problème : « pourquoi le fou vise f7 ? » — aucun mot-clé ne relie cette question à la page « Giuoco Piano ». Il faut chercher par le sens.

Indexer (une fois)

161 pages encyclopédiques (FR + EN, licences libres, périmètre signé) → 477 fiches → chaque fiche devient un vecteur de 1 024 nombres qui encode son sens (modèle d'embedding — FR et EN dans le même espace) → rangé dans Milvus, la base qui sait chercher « le plus proche » très vite.

Chercher (à chaque question)

la question devient un vecteur → similarité cosinus (l'angle entre les deux vecteurs : 1 = même sujet, 0 = sans rapport) → les 5 fiches les plus proches, dans le rayon de l'ouverture jouée uniquement → transmises au rédacteur avec leurs sources.

MesuréValeur

séparation sujet / hors-sujet (réglage des requêtes)0,29 → 0,50
question hors bibliothèquezéro fiche — réponse honnête (« ma bibliothèque ne couvre pas cette ouverture »)

Un mot de théorie — pourquoi ces garde-fous

Un modèle de langage prédit le mot suivant : il est fait pour être plausible, pas pour être vrai. D'où l'architecture : les faits viennent de systèmes vérifiables ; le LLM met en mots des faits annotés (« Fc5 — le Fou va en c5 »), à basse température, avec un gabarit déterministe en repli.

La preuve · La démarche

Mesurer avant de décider

1 · Le choix du LLM

Plan initial : API payante. Le banc de mesure (4 modèles locaux) a montré qu'un modèle de 3,2 Go répond en 3–7 s en bon français → local, 0 €. La décision a été révisée par les chiffres.

2 · Le gold set

25 questions étiquetées, figées avant tout réglage. Résultat 1,0 partout → l'étalon était trop facile. C'est une découverte, pas un échec — l'étalon v2 est l'axe suivant.

3 · L'abstention

Une question hors corpus citait des sources voisines (mesuré). Un seuil ne sépare pas (0,618 vs 0,619 !) → règle déterministe : le corpus n'est consulté que dans le rayon de l'ouverture jouée ou nommée. Vérifié : 5/5 pièges bloqués, 0 légitime sacrifiée.

Chaque chiffre de ce deck sort d'un notebook exécuté ou d'un run MLflow versionné — d'aucun autre endroit.

La partie 2 · Étude

L'étude du système d'analyse vidéo

La demande : indexer les vidéos par position (FEN), pas par titre — « cette position est expliquée à 4 min 32 ».

Le bénéfice chiffré

indexation automatique ≈ 0,10–0,15 €/vidéo contre 7,50–15 € à la main → ×50 à ×100

La limite dure : juridique

CGU YouTube : jamais les fichiers → MVP sur licences Creative Commons + transcripts d'abord, vision 2D ensuite ; le 3D (seul vrai entraînement de modèle) attendra les chiffres du pilote

Architecture MCP

4 serveurs d'outils réutilisables par tout agent FFE (youtube · vision · chess-tools · connaissances) + pipeline batch assumé pour la masse

Build MVP : 15–20 k€ · opex ~100–150 $/mois à 1 000 vidéos/mois · roadmap avec critères go/no-go chiffrés.

C — La décision d'abstention, l'histoire complète

1 · Préjudice mesuré (notebook 05) : une question hors corpus faisait citer 5 fiches adjacentes en sources.

2 · Le seuil pur est impossible (notebook 07, ci-contre) : pièges grossiers ≤ 0,548, mais entrelacement 0,618–0,663 — et les vraies questions scorent bas (démo : 0,629).

3 · La règle des rayons signés : le corpus n'est consulté que dans un rayon établi par la position (ECO) ou nommé dans la question ; hors manifeste → zéro fiche + réponse honnête. Filet à 0,58. 5/5 pièges bloqués par construction, 0 légitime sacrifiée — tests garde-fous versionnés.
